# 🪐 Cosmo — Explore the Universe

Cosmo is an aesthetic space-exploration website built with HTML, CSS, and JavaScript.

It lets users explore planets, discover famous space missions, and save their favorite planets.

## ✨ Features

- 🪐 Explore all 8 planets
- 🔍 Search planets
- ❤️ Favorite planets
- 💾 Save favorites with localStorage
- 💾 Save favorites with localStorage
- 🚀 Browse famous space missions
- ✦ Random space facts
- 🌌 Animated space-themed interface
- 📱 Responsive design
- 🌙 Dark cinematic UI
- ✨ CSS animations
- 🧭 Multi-page navigation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
